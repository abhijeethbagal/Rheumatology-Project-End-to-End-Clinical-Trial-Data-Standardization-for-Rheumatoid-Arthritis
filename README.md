# Rheumatology SDTM Project

## 📌 Project Overview

This repository demonstrates an end-to-end Clinical SAS programming project for converting raw clinical trial data into SDTM (Study Data Tabulation Model) datasets following CDISC standards.

The project simulates the workflow used by pharmaceutical companies and CROs for preparing submission-ready SDTM datasets.

---

## 🎯 Project Objectives

- Convert raw clinical trial datasets into SDTM domains
- Follow CDISC SDTM Implementation Guide (SDTMIG)
- Create SDTM specifications
- Develop reusable SAS programs
- Generate validated SDTM datasets
- Demonstrate industry-standard Clinical SAS programming workflow

---

## 🏥 Therapeutic Area

**Rheumatology**

Study focuses on data standardization for a Rheumatoid Arthritis clinical trial.
